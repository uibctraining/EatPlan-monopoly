# EatPlan-monopoly · 环马大富翁

吃货计划（eatplan.online）的第三款小游戏：**马来西亚文旅剧情 × 现金流策略棋盘游戏**。
纯静态网页（vanilla JS，无构建、无依赖），竖屏优先，可单机对战电脑（多人联网开发中）。

## 玩法

- 28 格环形棋盘（8×8），走遍马来西亚 13 州打卡点：吉隆坡双子塔、槟城升旗山、马六甲红屋、
  亚庇神山、古晋猫城、怡保老街……共 7 组 19 块地产。
- 起始 **RM2,500**，每轮经过起点领工资 **RM200**，默认 **10 轮**后按净资产结算（5/10/15 可选）。
- 落在无主地可买地；同组集齐 ×1.5 租金；环球银行可盖房（1→4 级）与抵押。
- **命运 / 机遇**卡：文旅剧情事件（马六甲娘惹餐、云顶缆车、免税店……）。
- **SST 消费税 10%**、**所得税 RM200**、**茶餐室**（休息，掷双可提前走）。
- 三连双数进茶餐室罚一轮；现金不足可向环球银行贷款（月息 10%），资不抵债即破产出局。
- 4 个角色：🐼 我、🦜 电脑·鹦鹉、🐯 电脑·老虎、🐱 电脑·猫咪；可选 1–3 个电脑对手。

## 运行

```bash
# 任意静态服务器即可
python3 -m http.server 8873
# 打开 http://127.0.0.1:8873/
```

## 结构

```
index.html      开局菜单 / 联机房间 UI / 主界面 / 弹层
css/style.css   深热带夜色 × 金黄（竖屏 390 优先，760px+ 桌面适配）
js/data.js      CFG 数值 / 分组 / 28 格棋盘 / 命运·机遇卡 / 角色
js/state.js     Game 引擎（掷骰、买地、盖房、抵押、贷款、破产、结算）
js/ai.js        电脑策略（买地 / 盖房 / 抵押）
js/ui.js        棋盘渲染、token 动画、各类弹窗、银行面板、缩放 / 小地图
js/main.js      回合循环、事件播放、开局菜单绑定
```
